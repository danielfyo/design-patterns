# Pattern lesson template

Every lesson in `patterns/<category>/<pattern>/README.md` follows this structure, in this order,
so readers always know where to look. Copy the skeleton below when adding or rewriting a lesson.
[Strategy](../patterns/behavioral/strategy/README.md) is the reference lesson.

## Conventions

- **Title:** the pattern's GoF name (`# Chain of Responsibility`).
- **Header block:** category, also known as, difficulty (⭐ beginner, ⭐⭐ intermediate,
  ⭐⭐⭐ advanced) and frequency of use (Low, Medium, High, Very high).
- **Names:** the same class/type names in every language, adjusting only casing conventions; the
  `I` prefix for interfaces is used in C# only.
- **Diagram:** a Mermaid `classDiagram`. Use `~T~` for generics, never `<T>`.
- **Expected output:** never written by hand. Keep the markers and run
  `python3 scripts/sync_readme.py`.
- **Real-world usages:** only well-known, verifiable APIs from .NET, JavaScript/React, Python and Go.
- **Links:** relative links to sibling lessons (`../state/README.md`), checked by
  `python3 scripts/check_links.py`.
- **Language:** English, second person, short paragraphs, practical before theoretical.
