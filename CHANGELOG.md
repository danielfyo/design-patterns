## 1.0.0

### Features

* All 23 GoF design patterns (5 creational, 7 structural, 11 behavioral), each with the same
  practical example in C# (.NET 8), TypeScript, React 19, Python and Go.
* A full lesson per pattern: problem, solution, UML diagram, code walkthrough, language notes,
  when to use it and when not to, pros and cons, real-world usages, related patterns and exercises.
* A React playground that renders the interactive demo of every pattern.
* Unit tests in every language (xUnit, pytest, `go test`, Vitest + Testing Library).

### Continuous Integration

* Every example is run in all four languages and compared with its `expected_output.txt`.
* Strict quality gates: .NET analyzers with warnings as errors, ruff + mypy `--strict`,
  `gofmt` + `go vet` + race detector, strict TypeScript; coverage summaries for every toolchain.
* CodeQL, OpenSSF Scorecard, Dependabot, Conventional Commit pull request titles and automated releases.
